## 🎯 这是什么？

**PDD Parser** 是一款专为**电商从业者**设计的拼多多商品数据采集工具。

**核心用途：电商上货**

> 通过本地代理自动采集拼多多商品的标题、价格、主图、详情图、SKU 规格等完整数据，
> 整理后导出为 Excel / CSV / 图文包等格式，方便你快速上架到自己的店铺。

### 典型使用场景

| 场景 | 说明 |
|------|------|
| 🛒 **电商选品** | 采集竞品商品数据，分析定价、标题、卖点 |
| 📤 **快速上货** | 批量采集商品信息，导出后直接导入到淘宝/拼多多/微信小店等平台上架 |
| 🖼️ **素材整理** | 自动下载商品主图、详情图、SKU 图，按商品分组整理 |

| 🎨 **图片处理** | AI 生成白底图、场景图、营销海报、去水印，内置图片编辑器 |

## 🏗️ 工作原理

```
┌─────────┐     HTTPS      ┌──────────────┐     HTTP      ┌─────────┐
│ 浏览器   │ ──────────────→ │ MITM 代理    │ ─────────────→ │ 拼多多   │
│ (用户)   │ ←────────────── │ :8080        │ ←───────────── │ 服务器   │
└─────────┘                 │              │                └─────────┘
                            │ inject.js    │
                            │ 注入采集脚本  │
                            └──────┬───────┘
                                   │ POST /api/ingest
                            ┌──────▼───────┐
                            │ Flask 后端    │
                            │ :5000        │
                            │ ┌──────────┐ │
                            │ │ SQLite   │ │
                            │ │ goods.db │ │
                            │ └──────────┘ │
                            └──────┬───────┘
                                   │
                            ┌──────▼───────┐
                            │ React 前端   │
                            │ 管理后台     │
                            └──────────────┘
```

1. **代理拦截** — mitmproxy 在 `127.0.0.1:8080` 开启 HTTPS 代理，拦截拼多多请求
2. **脚本注入** — 检测到商品页面后注入 `inject.js`，拦截 API 响应 + 监听 DOM 变化
3. **数据存储** — 采集到的数据通过 `/api/ingest` 存入本地 SQLite
4. **Web 管理** — Flask 后端提供 RESTful API，React 前端提供管理界面

## 🚀 快速开始

### 环境要求

- **Python 3.10+**（需加入 PATH）
- Node.js 18+（仅前端开发/重新构建需要，发布版已包含构建产物）

### 安装与启动（Windows）

```bash
git clone https://github.com/1tgbh/pdd-parser.git
cd pdd-parser
```

1. **安装依赖**：双击 `start.bat`（首次运行自动创建 `.venv` 并安装依赖；建议以管理员身份运行以便自动设置系统代理）
2. **安装 CA 证书**：服务首次启动一次后，右键 `install_cert.bat` → **以管理员身份运行**（安装 mitmproxy CA 根证书，仅在首次需要）
3. **登录采集**：浏览器自动打开拼多多，登录后**浏览商品即可自动采集**
4. **管理数据**：访问 <http://127.0.0.1:5000> 查看和管理采集结果
5. **导出上货**：选择商品 → 导出为 Excel/CSV/图文包 → 导入到你的店铺

### 手动安装（跨平台）

```bash
pip install -r requirements.txt
python pdd_proxy/start.py
```

CA 证书位置：`pdd_proxy/certs/mitmproxy-ca-cert.cer`（首次启动自动生成，每台机器证书唯一）。

### 配置 AI 功能（可选）

AI 图片/文案功能为可选，需在 Web 后台「设置」页面自行配置 API Key，或复制
`pdd_proxy/data/config.example.json` 为 `config.json` 后填写。

## 📁 项目结构

```
│   ├── inject.js          # 页面注入的 JS 采集脚本
│   ├── parser.py          # 数据解析模块
│   ├── storage.py         # 数据存储模块
│   ├── models.py          # 数据模型定义

│   ├── importer.py        # 数据导入模块
│   ├── wechat_export.py   # 微信小店导出
│   ├── monitor_scheduler.py # 价格监控调度器
│   ├── migrate.py         # 数据库迁移
│   ├── query.py           # 命令行查询工具
│   ├── web/
│   │   ├── app.py         # Flask Web API
│   │   └── ai.py          # AI 图片/文案服务
│   ├── frontend/dist/     # React 前端构建产物（已随仓库提供）
│   └── data/              # 运行时数据（数据库、图片，均已 gitignore）
├── frontend/              # 前端源码（React + TypeScript + Vite）
├── requirements.txt       # Python 依赖
├── start.bat              # Windows 一键启动（自动建 venv）
├── install_cert.bat       # CA 证书安装脚本
└── README.md
```

## ⚠️ 注意事项

- 建议以**管理员身份**运行（否则可能无法自动设置系统代理）
- 首次启动请允许**防火墙**访问网络
- 所有数据保存在 `pdd_proxy/data/` 目录，**不会上传任何外部服务器**；卸载前请备份
- CA 证书在首次启动时自动生成，每台机器唯一，**不会随仓库分发私钥**
- 杀毒软件可能误报代理类工具，请将本目录**加入白名单**
- AI 功能为可选，需自行配置 API Key

## 🔒 安全说明

- Web 后台仅绑定 `127.0.0.1`，不对外网开放
- `/api/ingest` 仅对注入脚本开放跨域，其余 API 仅接受本地来源
- 图片文件接口校验扩展名并限制在指定目录内，防止路径穿越
- AI API Key 仅保存在本地 `config.json`（已 gitignore），界面显示为掩码
